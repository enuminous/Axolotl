# AXOLOTL — EFMW Zoo #45

**Adaptive eXperimental Observation of Loss, Optimization, Transformation and Learning**

AXOLOTL is an experimental EFMW-inspired framework for evaluating whether a system can lose capability, reorganize, learn, and recover function through adaptation rather than simple restoration.

## Core question

> After damage or loss, can the system become functional again by learning a new configuration rather than merely returning to the old one?

## Primary outputs

- loss severity
- adaptation gain
- functional recovery
- transformation distance
- learning efficiency
- retained invariants
- recovery novelty
- adaptive resilience

## Quick start

```bash
python example.py
python benchmark.py
python ablations.py
python -m unittest test_axolotl.py
```
